# Answers

## 1. How to run

npm install
npm run dev

## 2. Stack & design choices

I used React with Vite because the app requires instant UI updates and component-based structure.

I used CSS Grid with auto-fit/minmax for responsiveness.

## 3. Responsive & accessibility

The app adapts from mobile to desktop using responsive grids.

Accessibility considerations:
- labels
- keyboard navigation
- visible focus states
- inline errors

## 4. AI usage

I used AI for brainstorming component structure and improving accessibility considerations.

## 5. Honest gap

I would improve animations and advanced accessibility testing if given more time.
